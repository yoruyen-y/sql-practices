## Current Project: Movies and Box Office

This project uses two related tables:

* `movies` — movie titles, directors, release years, and running times
* `Boxoffice` — ratings and domestic and international sales

The tables are connected through movie IDs. SQL queries can combine information from both tables to explore movie performance and calculate total sales.
